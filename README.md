# جافاسكريبت للباك اند — JS Backend School 🚀

موقع عربي متكامل لتعلم JavaScript بهدف الـ Backend فقط — من الأساسيات حتى بناء REST API حقيقي.

مبني على منهج قناة **Elzero Web School** (Learn JavaScript In Arabic 2021) مع فلترة أجزاء الفرونت (DOM / BOM / Canvas).

## التشغيل

افتح `index.html` في المتصفح مباشرة — مفيش Build ولا Dependencies.

أو بسيرفر محلي:

```bash
npx serve .
```

## المحتوى

- 10 مراحل / 29 درس: أساسيات → Functions → Objects → Async → Node.js → Express → MongoDB → JWT/Auth → مشروع متجر + Deploy
- كل درس: شرح + 3 أمثلة (سهل/متوسط/صعب) + تمرين + اختبار
- حفظ التقدم في localStorage + بحث فوري
